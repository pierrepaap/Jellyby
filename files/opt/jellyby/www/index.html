Select a field and press OK to type with the on-screen keyboard. Playback: "mpv (native)" = Pi 4 hardware decode via MPV; "browser" = Chromium tab. Server: jellyfin/emby for mpv, plex/url for browser. Item ID: optional Jellyfin/Emby item to play (empty = latest added). Credentials go in /etc/jellyby/players.json over SSH.
